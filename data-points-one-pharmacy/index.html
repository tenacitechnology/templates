  • Pharmacist of record hired, license posted; secure S2 license if carrying dangerous drugs.

Weeks 2-6: The Government Deal

File for
GAMOT.

  • Checklist of Documentary Requirements (Annex A)
  • Provider Data Record, from philhealth.gov.ph
  • Notarized Performance Commitment
  • Updated FDA License to Operate (drug retailer)
  • Certification of Availability of GAMOT medicines (Annex B)
  • Certification of Compliance to IT Requirements
  • Latest General Information Sheet, if a corporation
  • Submit all to PhilHealth Region VI, Western Visayas
  • Set up GAMOT App access for pharmacist and manager
  • Stock the 75-molecule list: amlodipine, metformin, losartan, paracetamol, antibiotics first
  • Post the GAMOT medicines list in-store, where patients see it
  • Fee waived 3 years, no pre-accreditation survey, validity up to 3 years

“Guimaras’ PhilHealth GAMOT pharmacy. Libre ang gamot mo dito.” Every member’s ₱20,000 benefit can only be claimed at an accredited pharmacy. Be the first door.
